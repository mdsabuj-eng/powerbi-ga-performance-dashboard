# Power BI GA Performance Dashboard

An interactive and fully automated Power BI dashboard designed to monitor GA performance, DD-wise targets and achievements, SIM sales, and key operational KPIs.

The dashboard transforms raw operational data into an interactive reporting solution with automated calculations, visualizations, and performance analysis.

---

## 📊 Dashboard Overview

This Power BI dashboard provides a comprehensive view of distributor-level performance and operational KPIs.

It allows users to monitor:

- Total GA
- GA Target
- GA Achievement
- Achievement %
- DD-wise Target vs Achievement
- SIM Sales Performance
- BP GA Contribution
- Top 5 Performing DDs
- Bottom 5 Performing DDs
- Daily Performance Trends
- DD-wise Detailed Performance

---

## ⚡ Fully Automated Reporting

The dashboard is designed with an automated reporting workflow.

Once the latest source data is downloaded or updated, simply open the Power BI report and click **Refresh**.

All calculations, KPIs, charts, tables, and performance visuals are automatically updated based on the latest available data.
