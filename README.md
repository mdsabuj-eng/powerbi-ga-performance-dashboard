# 📊 Power BI GA Performance Dashboard

An interactive and fully automated **Power BI dashboard** designed to monitor GA performance, DD-wise targets and achievements, SIM sales, and key operational KPIs.

The dashboard transforms raw operational data into an interactive business intelligence solution with automated calculations, data transformation, KPI monitoring, and dynamic visualizations.

## 📌 Dashboard Overview

This dashboard provides a comprehensive view of distributor-level operational performance and helps users quickly identify performance trends, target achievement, and areas requiring attention.

### Key Metrics

- Total GA
- GA Target
- GA Achievement
- Achievement %
- DD-wise Target vs Achievement
- SIM Sales Performance
- BP GA Contribution
- Top 5 Performing DDs
- Bottom 5 Performing DDs
- Daily Performance Trends
- DD-wise Detailed Performance

---

## ⚡ Fully Automated Reporting

The dashboard is designed with a **fully automated reporting workflow**.

Once the latest source data is downloaded or updated, the user only needs to open the Power BI report and click **Refresh**.

All calculations, KPIs, charts, tables, and performance visuals are automatically updated based on the latest available data.

```text

        ↓
